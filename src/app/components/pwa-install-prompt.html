Installatie instructies:

@if (isIOS()) {
  1. Tik op het ios_share deel-icoon onderaan (of bovenaan bij iPad)
  2. Scroll naar beneden en selecteer "Zet op beginscherm"
  3. Tik op "Voeg toe"
  4. Open de app vanaf je beginscherm
} @else if (isAndroid()) {
  1. Tik op het menu ⋮ rechtsboven in je browser
  2. Selecteer "App installeren" of "Toevoegen aan startscherm"
  3. Bevestig de installatie
  4. Open de app vanaf je startscherm
} @else {
  1. Klik op het more_vert menu-icoon in je browser (of de adresbalk)
  2. Selecteer "Installeren" of "App installeren"
  3. Bevestig de installatie
  4. Open de app vanaf je systeem
